### Changed

**`conformal_gate` — strict flag rule and a marginal-guarantee statement in `--fpr-bound` mode.** A target is now flagged only when its raw score is strictly beyond the threshold: `raw_score_comparator` is `>` for `higher_is_nonconforming` and `<` for `lower_is_nonconforming` (it was `>=` / `<=`). A score equal to the threshold is no longer flagged, so a new point tied with the threshold on discretized scores cannot push the flag rate above `fpr_bound`. Because the strict rule keeps the calibration flag count within `floor(q * n)`, the tie-raising step and its "degenerate calibration" abstention are gone: all-tied or over-tied calibration sets now return an available threshold that flags none of the calibration scores. The small-n abstention (`floor(q * n) = 0`) is unchanged. The output now also says the guarantee is marginal: with untied scores at n = 30 and q = 0.05 the realized false-positive rate exceeds 5% for about 21% of calibration draws, and a 95/95 tolerance statement at 0.05 needs at least 59 independent calibration texts.

### Fixed

`setec-voiceprint`: `check_corpus` no longer silently drops bytes that aren't valid UTF-8. It used to read with `errors="ignore"`, so a cp1252 file or a stray binary chunk was scored as if those bytes weren't there. Bad bytes now decode to U+FFFD and stay in the text that is scored, and each file record carries `decode_replacements`, the number of replacement characters made (genuine U+FFFD characters in the file are not counted). Preserve universal-newline normalization, so valid CRLF and CR input retains the prior hygiene-rule behavior. Thresholds remain unchanged; replacement tokens can change the strip-ratio denominator and therefore the resulting status. The records-cache version moves to 1.2, so existing caches are rescored rather than reused.

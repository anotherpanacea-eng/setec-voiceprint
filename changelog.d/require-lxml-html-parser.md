### Fixed

`setec-voiceprint`: HTML acquisition now uses the lxml parser only. `acquisition_core.html_to_text`, `acquisition_core._prestrip_html`, `acquire_magazine` (story list, story page and issue archive) and `acquire_blog` used to fall back silently to Python's `html.parser` when lxml could not be imported. The two parsers read malformed markup differently (`<p>a</div>b</p>` gives `ab` with lxml and `a\nb` with `html.parser`), so the stored text and content hash of a magazine, blog or other HTML piece depended on whether lxml happened to be installed. A re-acquisition on a host without lxml could then miss dedupe with no report. lxml was already pinned in `requirements-acquisition.txt` and installed in CI, so output on hosts that have it is unchanged; a host without it now fails with `bs4.FeatureNotFound` instead of producing different text. `_prestrip_html` stays best-effort for selector errors but no longer hides a missing parser.

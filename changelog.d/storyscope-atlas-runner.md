### Added

`setec-voiceprint`: `setec.calibration.storyscope_atlas`, an operator-side runner that builds StoryScope judge manifests for public-domain long-form fiction (`feat`, MINOR). It fetches Project Gutenberg texts, plans chapters and spec-79 segments, records stdlib counts per chapter, and writes Message Batches requests for four steps: Sonnet chapter cards, Sonnet segment features, an Opus gold subset with evidence spans, and Opus whole-work judgments from the cards. `emit` writes keyed spec-79 manifests for the 30 core features (accepted unchanged by `narrative_decision_long_form`), a feature table covering 40 adopted StoryScope taxonomy features and 19 new Victorian dimensions, per-feature Sonnet/Opus agreement, and actual cost from token usage (billed USD, plus the list-price equivalent of subscription-carried calls). `headless` runs the same requests through `claude -p` on the operator's subscription, with the step's model, effort and system prompt pinned and tools and local customizations off; it resumes after a usage limit and folds the Claude Code version into the recorded prompt version. `submit` refuses when committed spend plus the step's uncached ceiling exceeds `--max-usd`, and `plan` refuses works outside the public-domain boundary. It emits no envelope, band or verdict; it is not a capability surface. Adopted feature definitions are read from the operator's copy of the StoryScope authors' released taxonomy and are not redistributed. Selection and new definitions live in `references/storyscope-victorian/atlas-schema-v1.json`.

### Changed

Register `setec/preflight/common.py:_analysis` (preflight analysis fingerprint, NFC, case preserved) at its existing owner. The registry exposes it lazily through one more branch of its module `__getattr__`, so importing `textprims` still does not load the preflight package. The behavior digest binds `_analysis`, `text_rule_violation` and `domain_hash`. The inventory check requires those three defining functions, and the plain `hashlib` and `unicodedata` imports, to be single, undecorated and unchanged from the merge base. It pins the whole lazy getter and counts its `_analysis` branch as the row's import site. Relative imports inside a package now resolve against that package, so `from .common import _analysis` and `from . import common` reach the owner; storing to, aliasing or passing such a module object fails. Characterization passes bytes arguments as hex objects and covers NFC/NFD `Café`, CRLF and lone-CR folding, the Kelvin sign, kept case and tab, and the BOM, NUL, invalid UTF-8, C0, C1 and whitespace-only refusals. No consumer changed, and `_analysis` output is unchanged.

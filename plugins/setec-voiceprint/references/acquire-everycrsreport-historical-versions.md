# Historical CRS candidate discovery

The default acquirer still uses the latest-version CSV fields and writes a draft impostor manifest. Its legacy extractor drops the summary box and late author/contact trailer.

Opt in with --historical-versions, --until YYYY-MM-DD, --metadata-limit N, a private --output-dir, and a distinct private --out receipt path. Repeated --report-number values optionally limit the ordered report-number frame; without them, every distinct index number is considered. CSV latestPubDate and latestHTML do not decide historical eligibility. --max-items must cover N. The historical path rejects --emit-manifest, --allow-public-output, destructive stripping, and --content-selector; it extracts all recoverable visible body text after confirmed site chrome removal so sibling footnotes and appendices remain.

Each attempted report identity consumes one cap slot, including a missing targeted ID, invalid locator, or failed metadata request. The receipt records exact per-batch statuses and a continuation cursor. Resume with --after-report-number, --expected-index-sha256, and --resume-receipt from the previous successful bounded batch; use a new --out file. A changed decoded index or selection context refuses continuation. Resume also validates the prior receipt's named terminal statuses, per-report skip counts, acquired/files-written counts, and predecessor digest shape. Receipts are operator records, not proof that an earlier editable file is authentic. A non-resumable failure envelope is written for fatal index/cursor errors when a valid private output path exists; a cursor already at scope end refuses another batch. Partial batches and a cursor at the frame tail do not establish sample representativeness.

The selected version is the latest publication calendar date at or before --until, regardless of HTML availability. Missing/malformed dates and distinct same-day editions refuse verified chronology. A PDF-only selected edition yields no-html rather than an older substitute. Provider version IDs are opaque typed identities, not ordering keys.

Historical output contains candidate text and a private sidecar only; there is no baseline-shaped draft manifest. The source metadata and HTML hashes are over decoded FetchResult.text encoded as UTF-8. The acquirer does not retain raw source snapshots. Byline, rights, figure/structure completeness, and paragraph segmentation require document review. Recoverable visible text is retained conservatively; nontext figures and layout are not reproduced. Government-report status does not clear embedded third-party material. A dry run records would_write and zero files_written. A fully dispositioned zero-output batch writes its receipt before the ordinary nonzero exit unless --allow-empty or dedupe-only.
